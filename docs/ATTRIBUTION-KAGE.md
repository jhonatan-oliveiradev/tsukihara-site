# Kage educational port attribution

This project contains an educational Next.js/React port of structural and interaction ideas from **Kage** by Meng To.

Original references:

- https://github.com/MengTo/kage
- https://mengto.github.io/kage/

The port focuses on continuous scroll-driven camera choreography, persistent WebGL staging, foreground pinning, particles, atmosphere and editorial chapter pacing. Tsukihara's narrative, visual identity, characters, copy and game-specific assets are separate work.

Where practical, source-level concepts adapted from Kage are called out in code comments so the provenance remains clear as this project evolves.
