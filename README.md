# Tsukihara — Official Website

Cinematic website for **Tsukihara**, an original game project.

## Stack

- Next.js App Router + React + TypeScript
- Tailwind CSS v4
- React Three Fiber / Three.js
- GSAP + ScrollTrigger
- Lenis
- Prettier + `prettier-plugin-tailwindcss`

## Development

```bash
npm install
npm run dev
```

Quality checks:

```bash
npm run format:check
npm run lint
npm run build
```

## Creative direction

The experience is inspired by the editorial, continuous-scroll storytelling principles of Kage while using original implementation and Tsukihara-owned visual assets.
